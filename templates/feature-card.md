# 特征研究卡模板

填写后保存到 knowledge/features。空字段保持未填写，不用模型猜测。尚未支持的命题不能直接成为启用规则。

## 识别和范围

- feature_id：
- 标题与版本：
- 研究状态（proposed / supported / contradicted / retired）：
- 平台风险目标：
- 产品、业务阶段与判断对象：
- 需要检验的单一命题：

## 观测与来源

- 原始信号与派生方式：
- 可观测范围与不可见部分：
- 采集器、版本、端点与时间窗口：
- source_id / claim_id / 原始链接：
- 来源类型、发布日期和查阅日期：
- 正常反例和混杂因素：

## 验证与行动

- 怎样复现测量：
- 什么证据会否定或缩小该命题：
- 已执行验证与结果（未执行须写明）：
- 当前支持的结论与不支持的扩展：
- 用户下一步及适用前提：
- 费用、数据流、商业关联：
- 对应 rule_id 和复验方式：
- 复核日期与失效条件：
