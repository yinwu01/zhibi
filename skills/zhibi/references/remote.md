# VPS 检查、部署与验证

`check --host HOST --egress` 读取系统、资源、时钟、DNS 配置和网络出口。公共 DNS、UTC 或数据中心标签只作背景；不能据此推断账号风险。网络查询需在本次授权范围内。

先按 [runtime](runtime.md) 判断命令适合交互、一次性还是常驻运行。根据系统和现状准备依赖，安装后验证版本与实际启动。缺少 systemd 时可选择用户已有的其他托管工具，明确当前内置适配器仅支持 systemd。

`build` 默认给出计划；`--apply` 保存私人原值与执行回执。对同名服务，内置脚本拒绝符号链接、厂商 unit 和 drop-in，避免覆盖其他配置。替换普通 unit 前备份并记录原启用/运行状态，语法验证后启动，失败尝试恢复。

进程 active 和 enabled 分别说明当前运行与开机自起，均不证明应用健康。检查日志和实际应用操作；时区/语言仅按用户选择调整。当前 locale 步骤只是生成语言资源，不能声称已经改变所有登录会话的默认语言。

连接中断后先核对部署回执、服务和原值，不假定整体成功或自动重跑。恢复命令使用回执中的远端路径；保留回执直到用户确认本轮结果。
