# 配置需求

仅检查不需要 VPS。用户决定配置后，一次补齐当前阶段缺失的内容：

- 运行位置：优先用户指定的 Linux 服务器；没有则评估本机 PVM 的平台、内存和磁盘。远程路线补齐地址、用户、端口、已有密钥路径及需要的显式 SSH 配置；不擅自复用其他项目的机器或凭据。
- 网络出口：已有专用出口、需要准备的 VPS 出口，或用户明确接受的 direct；与运行位置分开确认。
- 想运行的命令、是否需要持续交互、工作目录和运行用户。
- 是否使用浏览器、具体浏览器和已有配置；远程路线通常为本地浏览器，PVM 路线可在 VM 桌面内运行，不强制指纹浏览器。

先检查已有配置和资源，尽量复用。缺少安装依赖时由 Agent 选择适合系统的官方安装方式并验证。命令由用户选择；Agent 可以协助解决安装和路径问题，不能擅自换成另一种服务。

私人启动脚本权限 600，凭据不要放在聊天、命令参数或报告中。计划写出会修改的对象和如何恢复；既有授权覆盖的操作不重复确认。
