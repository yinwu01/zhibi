# 数据流与隐私设计

本页区分当前 alpha 的数据流与后续设计要求。当前核心隐私行为有自动化测试；这不等于独立安全审计。

## 各类数据的接收方

| 过程 | 允许处理的数据 | 外部边界 |
| --- | --- | --- |
| 用户问诊 | 必要的阶段、用途、真实地区类别、入口与脱敏错误 | 云端 Agent 会收到对话中主动提供的内容 |
| 本地检查 | 白名单配置状态、版本、明确的观测结果 | 本地处理；不读取整份凭据或私人目录 |
| 浏览器探针 | 当前探针页可见属性、用户启用的请求结果 | 不读取 目标站点 Cookies 或其他网站内容 |
| 出口探测 | 向选定 HTTPS 端点发出的最小请求 | 对方能看到请求来源 IP 和必要网络元数据 |
| IP 情报 | 当前授权查询的 IP | 服务商能看到查询目标；费用与保留政策需披露 |
| AI 解释 | 经过字段筛选的摘要 | 云端模型服务会接收该摘要 |
| 社区反馈 | 用户选定并预览的脱敏信息 | 只有用户主动提交时才进入指定接收方 |

本地优先意味着尽量在设备内采集、处理和保留资料；不能声称绝对没有外部请求或模型数据传输。

## 不采集的内容

不收集密码、目标服务 Cookies、会话令牌、API Key 内容、SSH 私钥、验证码、完整卡号、证件、完整聊天和浏览记录。配置检查只提取必要键的非敏感状态；代理 URL 中的用户名和口令在本地剥离。

数据源 API Key 由本地进程按需使用，不能进入探针页面、模型上下文、日志和反馈包。默认使用 Header 或请求体。可选 Scamalytics v3 是官方接口要求 Key 位于 HTTPS 查询串的例外：只在用户选择并配置后使用，不跟随重定向，不打印 URL 或原始错误。

## 外部服务的启用

在检查计划中列出接收方、用途、发送字段、请求上限、潜在费用和禁用后的影响。已有选择在相同配置下复用；新增服务或数据范围变化时更新说明。报告记录实际使用的数据源。

基础功能不以购买 VPS、住宅代理或付费信誉服务为前提。公开网络错误、缺 Key、配额耗尽和供应商冲突都属于有明确含义的状态。

## 存储与分享

个人配置、原始观测和快照存放在仓库外的私有目录。原始数据、本地报告、Agent 摘要和社区反馈分别生成，禁止把整份本地报告直接传给模型或供应商。

导出使用接收方允许字段重新构建，而不是只靠正则替换。自由文本还需秘密检测和人工预览；Schema 校验只能证明结构，不能证明隐私。IP 哈希可以被枚举，不自动构成匿名化。Git ignore 也不能替代内容检查。

首版不默认上传案例、不加入遥测。清理与保留期限交给用户设置。任何未来网络回传接口都需明确新的数据接收方与权限范围。

## 0.1.0a1 实际落地

- 本地采集仅查看代理环境变量状态、Python/OS、客户端存在性和 resolv.conf 的解析器数量。代理地址与凭据不保留。
- 可选网络：api.ipify.org 接收 IPv4 出口请求；ipwho.is 接收查询 IP；api6.ipify.org 接收 IPv6 端点请求。目标站点探测需要用户显式声明目标域名（--target-domain）并且只在指定时发生；未声明时不发起任何站点请求。每个接收方每次最多一次，不携带会话、不调用认证接口、无遥测和自动重试。
- sent=true 表示发起过请求尝试；失败时无法据此声称未发送任何字节。
- 浏览器页面、保存的本地文本和 JSON 可能包含 IP。它们是私人结果，不是公开投稿摘要。
- Python 核心的共享报告不输出原始属性；Agent 使用单独生成的固定词汇摘要。
- Agent 摘要从固定规则主题和枚举状态重建，不直接复制用户自由文本、地址或来源响应。
- 默认私有目录 ~/.zhibi/，POSIX 权限 0700/0600；Windows ACL 待验收。
- timeline 只读取用户指定的 2–20 份快照，不扫描历史目录；输出变更类别而非 IP 等原值，时间和观测状态仍是私人信息。
- theory、learn、lab、guide、triage 本身均不联网。打开外部来源链接会使用浏览器的正常网络行为。
- 离线默认不联网；安装依赖和主动点击报告来源链接会有独立网络访问。

## 0.2.0a1 增强扫描

- `scan` 默认离线。选定供应商只查询测得的目标 IP；外部接收方写入请求计划与报告。
- `scan --network --reputation` 选择 ipwho.is、proxycheck.io、api.ipquery.io、api.stopforumspam.org；不读取密钥库。
  这些服务看到查询 IP 与本机查询请求的来源 IP，不接收浏览器属性或 目标服务 会话。
  ProxyCheck `tag=0` 关闭其正向检测日志，不保证它的所有服务日志均关闭；其他服务适用各自数据政策。
- IPQS/AbuseIPDB 用 Header，ipapi.is 用 JSON POST 传递密钥；这三家不使用 URL 密钥；不提供共享 Key 或自动购买。新增 Scamalytics 的官方 URL 例外见上文。
- `configure` 在本机终端隐藏输入，保存到私人 `~/.zhibi/providers.json`；`providers` 只返回配置状态。
- 高级浏览器探针包含 CCBaga/CheckCC 的有限采集实现；新增 CheckCC 权重仅作为显式选择的研究对照，不改变主结论。a3 可选字体探测使用 Canvas 文字宽度检查 26 个固定候选，不枚举完整字体、不导出像素或指纹哈希。
- WebRTC 使用用户选定的 Google STUN；出口、ICE 候选和 UA 只保存在本机浏览器导出/私人快照中。
- Agent 摘要包含固定发现、选定数值、覆盖状态和请求服务名，不含原始 IP、UA、组织自由文本或凭据。
- `scan-compare` 在本地读取两份指定快照，不扫描目录；输出是否同一测量对象及变化类别。
- 完整报告可能保留供应商的网络组织名称，用于本地核对；HTML 转义文本，Agent 摘要不复制这些字段。
- `scan` 生成的本机私人 HTML 显示所测 IP、浏览器/Agent 路径与基础浏览器观测。`report.json` 和 Agent 摘要仍不包含原始 IP。
- 离线重排旧报告可显式提供 `report --snapshot <同一次扫描的 snapshot.private.json>`；工具验证样本标记、时间和检测对象对应关系，只读取指定文件，不自动搜索私人快照。重排不更新测量时间，也不新增联网查询。
- `dns --network` 查询固定的 Akamai 诊断名称；当前 DNS 链路可能转发递归出口及 ECS 子网。
  不遵循 HTTP 代理的假设，缓存命中不保证联系了权威端。原始解析器地址和子网只在私人快照保存。
  存在自定义 `.digrc` 时不执行；不读取或更改其内容。无 dig/查询失败时保留未知，不自动部署服务。

## 0.2.0a3 可选浏览器观察

- 六组检查分别勾选，默认全部关闭；不增加网络接收方，也不读取密钥。
- UTC 偏移、语言变体、UA/Client Hints、设备/容器标记、逻辑 CPU 数和字体匹配留在浏览器导出与私人快照中，完整读数只展示在本地 HTML。
- Agent 摘要和 `report.json` 只保存检查时间、固定模块名和状态，不携带这些原始属性。
- 定位权限只调用当前页面的 `Permissions.query`，不请求坐标或弹出授权；不查询其他网站权限。
- 不调用高熵 Client Hints、完整本地字体访问、摄像头、麦克风，也不创建持久设备标识。

## 0.3 可选扩展

Canvas 哈希、WebGL/Audio、TLS 与 DNS 读数仅写私人报告；脱敏分享重新构造字段，不复制原始报告。浏览器 TLS 向 tls.peet.ws 发无认证请求；DNS 只使用用户提供的 HTTPS 观测端。IPsum/DROP 下载整份公开名单后本地比对，下载站仍能看到请求来源 IP。

`session` 仅绑定 127.0.0.1，随机短时路径、严格 Host/Origin、一次接收；不提供私人报告下载或目录浏览。`suite` 不修改环境。维护命令只有显式应用才改配置，并保存原值；工作目录加密备份是独立选择，不意味着需要读取 目标服务 Cookie 来做检测，备份文件不交给 Agent 或第三方。
