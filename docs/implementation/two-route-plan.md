# 双路线实施与验收

目标：优先远程 Linux；没有远程运行服务器时提供本地 PVM Linux VM。运行位置和网络出口分别配置。最终交付包括代码、主 Skill、参考说明、中英文 README、实测记录及 GitHub 推送。

## 当前核对（2026-11-12）

现有 `connect.py` 提供 SSH/SOCKS、交互终端和独立导出；`sandbox.py` 提供 Linux bwrap 与代理模式；`runtime_service.py` 提供 systemd 用户服务；`browser_workspace.py` 提供专用 Chromium 配置。它们不是完整 VM 管理器，也没有按项目保存的统一入口。原有真实 Linux/SSH 检查脚本可复用，但历史成功记录不能替代新增功能验收。

工作树中 README.md 有用户未提交的重写稿；以该稿为写作基础补齐，不恢复旧版覆盖。
