# Skill 整合交付验收

更新：2026-10-19，0.2.0a3。目标是以 Skill 为入口，内置本地执行能力；作者当前序言保持原文。

| 要求 | 当前证据 | 边界 |
| --- | --- | --- |
| 一次安装的 Skill | 完整 ZIP、标准库 zipapp、仓库外 Python 3.9 隔离验证 | 需要 Python；宿主自动发现另行验收 |
| 成熟项目复用 | 固定 CCBaga/CheckCC 源码哈希、MIT 许可、运行中的适配代码和迁移用例 | 未把整个上游产品或 AGPL 代码并入 |
| 多源 IP 情报 | 七个适配器、参数与覆盖、原始评分、故障与冲突处理；四家免 Key 来源在 AdsPower 出口实测 | IPQS/AbuseIPDB/keyed ipapi 的现场测试需要用户自己的免费或付费 Key |
| 浏览器与 Agent 路径 | 双栈、相近时间与同端点比较、实际浏览器导入；Chrome UI 验收 | 诊断端点不能代表所有目标网站路径 |
| WebRTC / DNS | 高级 ICE 探针；独立 dig/ECS 观察并完成真实 DNS 查询 | 浏览器真实 DNS 与外部 STUN 路径未由开发自动化替用户确认 |
| 主动风控解释 | 每项发现连接动机、特征、依据、正常反例、下一步 | 平台内部策略保持未知，不生成封号概率 |
| Graph / 时间 | 来源依赖、观测、解释、行动的证据图；同上下文复查 | 完整网络实体图与平台账户图不在已实现范围 |
| 隐私 | 默认离线、密钥隔离、私人快照、最小模型摘要、失败不泄漏原始异常 | 公网测量和情报查询需要明确外部接收方 |
| 实操教程 | 安装、首份报告、增强来源、浏览器、DNS、错误处理、复查；作者专区 | 作者未提供的注册细节不代写为真实经验 |
| 交付质量 | 113 项 Python 行为测试、浏览器深入检查逻辑与实机导出导入验证、独立 Skill 与 wheel 验收、许可证和链接检查 | 远端 CI、跨系统实机与账号效果尚未验证 |

详细命令与结果见 [验收记录](validation.md)。本轮产出可审查、可安装的本地发布包。
GitHub 发布、商业情报现场覆盖和长期用户效果各自需要独立证据，不由本地测试代替。

当前下载、安装和无 Key 实测见[首次使用验收](../archive/onboarding-validation.md)。仓库已私有发布，远端 CI 仍有账单/支出限额阻塞。

## 完整覆盖验收

以[能力覆盖清单](capability-coverage.md)逐项验收。当前 v0.2.0a3 的基础链路已验证，不等于完成上游能力覆盖。已实现、部分覆盖、待补齐与待实测分别记录；未实现项不因 optional 而自动通过。本轮新增六组可选浏览器检查，已接入本地报告；完整系统交叉核对、额外情报来源等仍未补齐。
